The Scrubi Validation Engine

Integrate clinical-grade email verification into your stack. Our API leverages 14 distinct validation layers, from syntax checks to deep SMTP handshakes, ensuring your deliverability remains surgical.

Authentication Protocols

All API requests must include your API key in the X-Scrubi-Key HTTP header. Your API keys carry significant privileges, so keep them secure.

cURL Request 
curl -X GET "https://api.scrubi.com/v1/validate?email=user@example.com" \
  -H "X-Scrubi-Key: YOUR_API_KEY" \
  -H "Accept: application/json"

Query Parameters

Parameter Type Description
email string The email address to be validated. Must be URL encoded.
strict boolean If true, performs a deep SMTP handshake to verify mailbox existence.
timeout integer Maximum duration for validation in milliseconds. Default is 5000ms.

Response Schema

Successful responses return a 200 OK status code and a JSON object containing the validation results.

info

The score property is a float from 0.0 to 1.0 representing our confidence level in the address validity.

JSON Output 
{
  "status": "success",
  "data": {
    "email": "valid@user.com",
    "format": true,
    "dns": true,
    "smtp": true,
    "disposable": false,
    "score": 0.98
  }
}
