EMAIL_SCRUBBING
CORE_API

The Scrubi Core API provides high-precision email validation, MX record analysis, and deliverability scoring. Engineered for millisecond-latency and clinical accuracy.

01 // Authentication

To authenticate your requests, include your API key in the X-API-KEY header. Keep your keys secure; they grant full access to your scrubbing credits.

Required Header

X-API-KEY: your_scrubimail_api_key...

02 // Single Validation

POST /v1/validate

Performs a 12-point clinical scrub of a single email address. Checks syntax, DNS, SMTP, and disposable providers.

Body Parameters

email string (required) The target email address.
strict_mode boolean Enable aggressive filtering.

03 // Batch Scrubbing

layers

High-Velocity Processing

Submit up to 10,000 emails in a single array. The Scrubi engine distributes tasks across our node-clusters for concurrent validation.

cURL / Node.js / Python 
curl -X POST https://api.scrubi.com/v1/validate \
  -H "X-API-KEY: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "dev@scrubi.io",
    "strict_mode": true
  }'
200 OK — Response Body 142ms 
{
  "status": "valid",
  "score": 0.98,
  "checks": {
    "syntax": true,
    "mx_records": true,
    "disposable": false,
    "smtp_repro": "success"
  },
  "suggestion": null
}
